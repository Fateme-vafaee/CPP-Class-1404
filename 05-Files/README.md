# 05-Files

## English

### Overview
This folder contains C++ Files practice exercises such as average of numbers in a file, finding a string in a file, add information in a file, and printing the content of a file.

### Files Description

#### `average_of_files_info.cpp`
- **Purpose**: Opens a text file, reads the numbers inside it, and calculates their average.
- **Concepts**: File handling, input/output streams, loops, arithmetic operations
- **Input**: A text file containing numbers
- **Output**: Average of the numbers in the file

#### `find_string_in_file.cpp`
- **Purpose**: Receives a string from the user and searches for it inside a text file to determine whether it exists or not.
- **Concepts**: File handling, strings, searching, loops
- **Input**: A string entered by the user and a text file
- **Output**: Indicates whether the string exists in the file or not

#### `print_file.cpp`
- **Purpose**: Opens a text file and prints its contents to the output.
- **Concepts**: File handling, input/output streams, loops
- **Input**: A text file
- **Output**: Contents of the text file

#### `register_scores.cpp`
- **Purpose**: Receives a course name and its grade from the user and saves them into a text file.
- **Concepts**: File handling, strings, input/output streams
- **Input**: Course name and grade entered by the user
- **Output**: A text file containing the course name and grade



## فارسی

### نمای کلی
این پوشه شامل تمرین‌های C++ مربوط به کار با فایل‌ها است؛ از جمله محاسبه میانگین اعداد داخل فایل، جستجوی یک رشته در فایل، افزودن اطلاعات به فایل و چاپ محتوای فایل.

### توضیح فایل‌ها

#### `average_of_files_info.cpp`
- **هدف**:یک فایل متنی را باز می‌کند، اعداد داخل آن را می‌خواند و میانگین آن‌ها را محاسبه می‌کند.
- **مفاهیم**: کار با فایل، جریان‌های ورودی/خروجی، حلقه‌ها، عملیات ریاضی
- **ورودی**: یک فایل متنی شامل اعداد
- **خروجی**: میانگین اعداد موجود در فایل

#### `find_string_in_file.cpp`
- **هدف**: یک رشته از کاربر دریافت می‌کند و داخل یک فایل متنی جستجو می‌کند تا مشخص شود آیا این رشته وجود دارد یا خیر.
- **مفاهیم**: کار با فایل، رشته‌ها، جستجو، حلقه‌ها
- **ورودی**: یک رشته که توسط کاربر وارد می‌شود و یک فایل متنی
- **خروجی**: اعلام می‌کند که رشته در فایل وجود دارد یا خیر

#### `print_file.cpp`
- **هدف**: یک فایل متنی را باز می‌کند و محتوای آن را در خروجی چاپ می‌کند.
- **مفاهیم**: کار با فایل، جریان‌های ورودی/خروجی، حلقه‌ها
- **ورودی**: یک فایل متنی
- **خروجی**: محتوای فایل متنی

#### `register_scores.cpp`
- **هدف**: نام یک درس و نمره‌ی آن را از کاربر دریافت می‌کند و آن‌ها را در یک فایل متنی ذخیره می‌کند.
- **مفاهیم**: کار با فایل، رشته‌ها، جریان‌های ورودی/خروجی
- **ورودی**: نام درس و نمره‌ای که توسط کاربر وارد می‌شود
- **خروجی**: یک فایل متنی شامل نام درس و نمره
